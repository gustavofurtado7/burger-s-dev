# 🍔 Burger's Dev

Projeto desenvolvido com o objetivo de **revisar e colocar em prática importantes métodos de manipulação de arrays em JavaScript**.

O **Burger's Dev** é uma aplicação inspirada em um cardápio de hamburgueria, desenvolvida durante meus estudos de desenvolvimento web. O projeto utiliza **HTML5, CSS3 e JavaScript**, com foco principalmente nos métodos `forEach()`, `map()`, `reduce()` e `filter()`.

## 🚀 Sobre o projeto

O projeto foi desenvolvido como uma forma prática de revisar conceitos importantes de JavaScript relacionados à manipulação de arrays.

Através de um cardápio de produtos, é possível aplicar diferentes funcionalidades e visualizar como cada método pode ser utilizado para manipular e transformar os dados.

O **Burger's Dev** foi uma oportunidade para reforçar meus conhecimentos e compreender melhor como trabalhar com coleções de dados utilizando JavaScript.

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura da aplicação
* **CSS3** — estilização e construção da interface
* **JavaScript** — lógica e manipulação dos dados

## 📚 Conceitos praticados

Durante o desenvolvimento deste projeto, revisei e pratiquei os seguintes conceitos:

### 🔁 `forEach()`

Utilizado para percorrer os elementos de um array e executar uma determinada ação para cada item.

### 🗺️ `map()`

Utilizado para percorrer um array e criar um novo array a partir da transformação de seus elementos.

### ➕ `reduce()`

Utilizado para reduzir os elementos de um array a um único valor, sendo especialmente útil para realizar cálculos, como a soma dos valores dos produtos.

### 🔍 `filter()`

Utilizado para filtrar os elementos de um array de acordo com uma determinada condição.

Além desses métodos, também foram praticados:

* Manipulação do DOM
* Eventos em JavaScript
* Funções
* Arrays e objetos
* Arrow functions
* Template literals
* Operadores matemáticos
* Condicionais
* Atualização dinâmica da interface
* Integração entre HTML, CSS e JavaScript

## 🎯 Objetivo

O principal objetivo deste projeto foi **revisar e consolidar meus conhecimentos sobre os métodos `forEach()`, `map()`, `reduce()` e `filter()`**.

Em vez de estudar esses conceitos apenas de forma teórica, desenvolvi uma aplicação prática para compreender melhor como cada método funciona e em quais situações eles podem ser utilizados.

Este projeto contribuiu para fortalecer meus conhecimentos em **manipulação de arrays e lógica de programação com JavaScript**.
